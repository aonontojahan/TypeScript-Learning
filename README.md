A personal learning repository where I document my journey of mastering **TypeScript** — one concept at a time. Each topic lives in its own file with simple, runnable examples and notes explaining the *why* behind the code.

## 📂 Topics Covered

| File | Concept | What's Inside |
|------|---------|---------------|
| [`src/string.ts`](src/string.ts) | `string` | Template literals, concatenation, `toUpperCase()`, `toLowerCase()`, `.length` |
| [`src/number.ts`](src/number.ts) | `number` | Integers, floats, `NaN`, `Infinity`, arithmetic operations |
| [`src/boolean.ts`](src/boolean.ts) | `boolean` | Typed booleans with conditional (`if/else`) logic |
| [`src/bigint.ts`](src/bigint.ts) | `bigint` | Numbers beyond `Number.MAX_SAFE_INTEGER` using `BigInt()` |
| [`src/null.ts`](src/null.ts) | `null` | Representing the absence of a value, `string \| null` union type |
| [`src/undefined.ts`](src/undefined.ts) | `undefined` | How functions without a `return` produce `undefined` |
| [`src/anyvsunknown.ts`](src/anyvsunknown.ts) | `any` vs `unknown` | Why `unknown` is safer, and narrowing with `typeof` checks |
| [`src/neverdatatype.ts`](src/neverdatatype.ts) | `never` | Functions that never return — infinite loops, always-throwing functions |

> 🚧 This repo grows as I learn — new topics (arrays, tuples, enums, interfaces, generics...) are on the roadmap below.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- TypeScript installed globally, or use `npx`:

```bash
npm install -g typescript
# or run it without installing:
# npx typescript
```

### Compile & Run

Every file in `src/` is a standalone example. Compile the whole project:

```bash
tsc
```

This compiles everything from `src/` into `dist/` (as configured in `tsconfig.json`). Then run any topic you like:

```bash
node dist/string.js
node dist/number.js
node dist/anyvsunknown.js
```

### Watch Mode (auto-recompile on save)

```bash
tsc --watch
```

## ⚙️ Compiler Configuration

Key options from [`tsconfig.json`](tsconfig.json):

| Option | Value | Why |
|--------|-------|-----|
| `rootDir` | `./src` | Source files live in `src/` |
| `outDir` | `./dist` | Compiled JS is emitted to `dist/` |
| `target` | `esnext` | Compile to the latest JavaScript features |
| `module` | `commonjs` | Output runs directly with Node.js |
| `strict` | `true` | All strict type-checking enabled — the recommended way to learn |
| `sourceMap` | `true` | Enables debugging the TS source in DevTools |
| `declaration` | `true` | Generates `.d.ts` type definition files |
